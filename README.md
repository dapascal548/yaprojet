# GESPRO — Solution de Gestion de Projets & Suivi Budgétaire

Application Web de gestion de projets, suivi budgétaire en temps réel, devis détaillés et validation des dépenses développée pour **YA CONSULTING**.

## 🛠️ Architecture Technique
* **Backend** : Laravel 11 / PHP 8.2+
* **Frontend** : Laravel Blade + Tailwind CSS (CDN)
* **Base de données** : SQLite / MySQL
* **Sécurité** : Chiffrement AES-256 des montants financiers et journal d'audit
